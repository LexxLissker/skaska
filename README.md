# «Заморозка»

PWA-магазин замороженных полуфабрикатов ручной лепки: каталог → карточка товара
с конфигуратором → корзина → оформление с плановой доставкой по зонам → оплата.

Реализация дизайн-прототипа из `docs/design/` на Vendure (бэкенд) и Next.js (витрина).

## Стек

| Слой | Технология |
|---|---|
| Бэкенд | Vendure 3.7, PostgreSQL 16 |
| Витрина | Next.js 16 (App Router), TypeScript, Tailwind CSS v4 |
| Инфраструктура | Docker Compose, GitLab CI, Caddy |

## Структура

```
apps/
  api/                     Vendure: каталог, заказы, доставка, оплата
    src/data/              данные каталога и зон, перенесённые из прототипа
    src/plugins/           плагины (см. ниже)
    src/seed/              наполнение пустой базы
  web/                     витрина Next.js
docs/design/               дизайн-хендофф: прототип, README, скриншоты, токены
scripts/                   вспомогательные скрипты
```

## Ключевые архитектурные решения

**Опции товара — не варианты Vendure.** В конфигураторе пять групп: вес (2) ×
тесто (6) × жир (4) × цвет (4) × текстура (2). Вариантами это дало бы 384 варианта
на товар и ~37 000 на каталог. Поэтому вариантом остаётся только вес, а остальные
четыре группы — custom fields на позиции заказа; наценка применяется
в `ConfiguratorPriceCalculationStrategy`. Цена всегда считается на сервере из
справочника наценок, подделать её запросом нельзя.

**Доставка плановая, а не «по требованию».** У каждой зоны своё расписание рейсов,
своя стоимость и свой порог бесплатной доставки. Покупатель выбирает конкретный
рейс, оформить заказ нужно до дедлайна приёма. Расчёт живёт в `ShippingCalculator`
внутри Vendure — витрина только показывает посчитанное.

**Промокоды — штатные промоакции Vendure** с купоном, без своего кода.

**Корзина серверная** — `activeOrder` Vendure по сессионному токену, а не состояние
в браузере.

## Локальный запуск

Нужны Docker и Node 20+.

```bash
cp .env.example .env
docker compose up -d db
npm install
npm run seed --workspace=@zamorozka/api
npm run dev:api
```

- Shop API: http://localhost:3000/shop-api
- Admin UI: http://localhost:3000/admin (superadmin / superadmin)
- Витрина: http://localhost:3001

### Особенность этой машины

В системном PATH прописан `C:\nvm4w\nodejs` — симлинк на профиль другого
пользователя Windows, читать его нельзя, и `npm` падает с EPERM. Системный PATH
идёт раньше пользовательского, поэтому перед работой подключи рабочий Node:

```bash
. .\scripts\dev-env.ps1
```

## Открытые вопросы к каталогу

Каталог из прототипа сгенерирован формулой: те же 16 начинок применены ко всем
категориям, отсюда позиции вроде «Вареники, Говядина/свинина». Раскладка начинок
по подкатегориям в прототипе тоже отсутствует — сейчас она круговая, как заглушка.
Реальный каталог и раскладку задаёт владелец магазина в админке.
